# Что добавляет этот форк

Форк [Yurich-ru/yandex-ads-mcp](https://github.com/Yurich-ru/yandex-ads-mcp) (MIT).
База: апстрим на коммите `6403ac6` (сентябрь 2026, версия 1.2.0). Ветка `fork-main` — это та сборка,
которая каждый день работает у меня на сервере с живыми кабинетами Директа.

Апстрим отлично читает кабинеты и правит объявления. Чего ему не хватало для ежедневной работы —
денег: стратегии, ставок, дневного бюджета. Форк добавляет **19 инструментов, 13 из них про деньги**.

## Денежный слой — `tools_money.py` (13 инструментов)

Штатный `campaigns.get` в апстриме не запрашивает типовые поля кампании, поэтому стратегия кампании
не видна вообще, а сервиса `strategies` (пакетные стратегии) нет. Все суммы в аргументах и ответах —
в рублях, в API уходят микроединицы.

| Инструмент | Что делает |
|---|---|
| `yd_money_overview` | Полная картина по деньгам кампаний: стратегия на поиске и в сетях с цифрами, дневной бюджет, пакет |
| `yd_account_money` | Деньги аккаунта: валюта, режим оплаты, овердрафт, НДС |
| `yd_strategy_set` | Стратегия одной кампании. Незаданные параметры наследуются, а не обнуляются |
| `yd_daily_budget_set` | Дневной бюджет и режим показа; `amount=0` снимает ограничение |
| `yd_strategies_get` | Пакетные стратегии аккаунта |
| `yd_strategies_add` | Создать пакетную стратегию, включая ставки за конверсию по целям |
| `yd_strategies_update` | Изменить пакетную стратегию; применяется сразу ко всем кампаниям пакета |
| `yd_strategies_action` | Архивировать / разархивировать пакет |
| `yd_package_strategy_link` | Привязать кампанию к пакету или собрать пакет из стратегии кампании |
| `yd_package_strategy_unlink` | Отвязать кампанию, задав ей собственную стратегию |
| `yd_bids_auction_get` | Аукцион по фразам: какой объём трафика даёт текущая ставка и сколько стоит каждый объём |
| `yd_bids_set_by_traffic` | Автоставки под целевой объём трафика на поиске и охват в сетях |
| `yd_bids_manual_set` | Ручные ставки: явные или «по объёму трафика» для каждой фразы, с потолком |

## Прочее

- **Проверка картинок до загрузки** (`image_formats.py`). Директ принимает почти любую картинку, но
  привязать к объявлению можно только допустимые форматы; остальные молча оседают в библиотеке.
  `yd_ad_images_add` и `yd_ads_add_image` отсеивают их заранее и объясняют причину. `force: true` —
  прежнее поведение.
- **Вордстат через сервисный аккаунт Облака** (`YC_SA_KEY_FILE` или `YC_API_KEY`). OAuth-токены,
  выпущенные после 01.06.2026, Облако больше не меняет на IAM-токен, и Вордстат без этого не работает.
  Для `YC_SA_KEY_FILE` нужен `pip install "pyjwt[crypto]"`.
- **Классификация пишущих вызовов.** Все новые инструменты, которые что-то меняют, проходят через
  общие предохранители апстрима: `YD_READONLY` блокирует их, `YD_CONFIRM` требует `confirm=true`,
  без него возвращается предпросмотр.
- Починены хендлеры ставок и чтение нескольких инструментов, которые падали на реальном API.

## Как развернуть

```bash
git clone -b fork-main https://github.com/guyfullin10-lgtm/yandex-direct-mcp.git
cd yandex-direct-mcp
python3 -m venv venv && venv/bin/pip install -r requirements.txt
cp .env.example .env   # вписать YD_OAUTH_TOKEN, при агентском доступе — YD_LOGIN
```

Подключение к Claude Code (stdio):

```bash
claude mcp add yandex-direct -- /path/to/yandex-direct-mcp/venv/bin/python /path/to/yandex-direct-mcp/server.py
```

Рекомендую начать с `YD_CONFIRM=true`: любое изменение денег сначала придёт предпросмотром, и только
повторный вызов с `confirm=true` его применит. Для чтения без риска — `YD_READONLY=true`.

## Синхронизация с апстримом

`master` повторяет апстрим. Свежий апстрим подтягивается мерджем в `fork-main`; наши изменения
живут в отдельных модулях (`tools_money.py`, `image_formats.py`) и в точечных правках `server.py`
и `tools_direct_extra.py`.
